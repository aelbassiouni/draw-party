# Draw Party

An offline, in-person drawing and guessing game for Android and iPhone. Share one phone, draw on paper or a whiteboard, and guess aloud.

## Project status

Design and specification stage. Production implementation has not started, and the technical framework has not been selected.

- Team and free-for-all modes
- English and Egyptian Arabic, with independently selectable interface and word languages
- Local saved groups and unfinished-game recovery
- Adaptive phone and foldable-screen layouts
- Planned free, ad-free first release with no accounts or analytics
